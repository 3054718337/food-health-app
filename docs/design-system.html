食刻设计系统SHIKE DESIGN KIT

一个用于「今日饮食健康评估」的轻量设计规范：暖纸底色 + 深绿主色，数字用等宽字距，信息按「结论 → 依据 → 行动」排列。

版本 v1.0 Web · 响应式 无第三方 UI 库 对比度 ≥ 4.5:1

设计原则

Principles
1

先给结论

分数、等级、一句话判断放在最上方。用户不需要滚动就能知道「今天吃得怎么样」。

2

依据可核对

每个分数都对应具体克数与参考量，六维条和指标卡让「为什么是这个分」有据可查。

3

行动要具体

建议不写「多吃蔬菜」，而写「还差 120 g，约等于一份蒜蓉西兰花」，并直接给出明日三餐。

动效与可访问性

Motion · A11y

动效克制

仅两处：报告淡入上移 300ms，分数环与条形 700–800ms 缓动填充。尊重 prefers-reduced-motion。

键盘可达

所有可交互元素保留 2px 绿色焦点环；份量器有 aria-label；弹窗使用原生 dialog 并自动聚焦。

对比度

正文 #1C2A24 对 #FFFDF8 约 13:1；辅助文字 #6E7C74 约 4.6:1；颜色之外同时用文字说明状态。
